# HiPaw 工作台视觉规范

用户明确偏好白色主题。保留参考 [即梦公开首页](https://jimeng.jianying.com/ai-tool/home/) 整理的布局与控件层级，采用白色面板、浅灰工作区和少量蓝色强调，为 HiPaw 的兽医与设计师工作流程重新组织。它不是即梦官方设计系统，不使用即梦的 Logo、作品或专有字体。

颜色通过主题变量集中维护。成功、待处理、错误保留各自语义颜色。医院目前没有既定品牌配色，院方色板默认为空。界面采用上述白色主题；生图不自动带入旧的深绿、黄色，也不受界面主题颜色约束。以后可在品牌中心开启可选的创作配色。医学图片及吉祥物原图不跟随界面主题改变。

## 结构

- 桌面导航宽 104px，使用统一线性图标和中文标签；窄屏改为横向滚动导航。
- 设计画布左侧为 268–320px 的生图设置栏，剩余空间用于实际画布。设置可独立滚动，生成按钮留在栏底。
- 素材、生成记录、保存作品和专注模式放在画布顶部；图片上传、撤销、导出与缩放沿用画布本身的工具。
- 专注模式隐藏全局导航和生图设置，保留退出入口。
- 品牌中心使用主编辑区与状态侧栏；模型配置收起，按需展开。
- 资产详情保持点击打开弹窗，保留筛选与列表位置。

## 控件

- 正文和输入内容通常为 16px，常用标签 14px，辅助信息 12–13px。
- 页面标题 20–24px，工作区内标题 16–18px；用字重和间距建立层级。
- 面板圆角 16px，输入与按钮 9–12px。普通控件避免厚边框和强阴影。
- 主按钮使用蓝底白字；选中态使用浅蓝背景，普通按钮保持白色或浅灰。
- 图标使用已有 Lucide 图标。悬停和选中状态分别表现，禁用状态不可点击。
- 窄屏将画布置于设置栏上方；弹窗内容独立滚动，控制条避免超出可视宽度。

## 实现与验证

工作台主题位于 `outputs/hipaw.css`，在原型基础样式之后加载。画布使用自身的 `canvasThemes`；两者使用协调的白色与浅灰背景。

已完成静态构建、类型检查、样式解析和页面资源可访问性检查。尚未完成浏览器视觉及操作验收；真实生图仍取决于账户和模型配置。
